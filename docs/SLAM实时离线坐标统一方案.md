# SLAM 实时地图与离线地图坐标统一方案

## 目标

加载 `.slammap` 后再回放 PCAP 时，让实时点云、实时泊位结果与已加载的历史地图处于同一显示坐标系；历史地图继续使用黄色，实时地图继续使用绿色并叠加显示。

## 最小改动方案

1. 离线地图加载流程保持现状，继续使用 `SlamMapGeoCorrector` 将历史关键帧校正到 ENU 地图坐标。
2. 加载离线地图后，等待第一个带有效 `geo_reference` 的实时关键帧，计算一次固定变换：
   `T_enu_map = T_enu_lidar * inverse(T_map_lidar)`。
3. 对后续实时关键帧、实时里程计和实时扫描点云统一应用该变换，再送入界面地图层和泊位同步器。
4. 如果实时数据没有有效地理参考，保持原有坐标处理，不阻断 PCAP 回放或 SLAM 建图。

该方案不修改 UDP 投递协议、历史地图格式或泊位检测算法，只修正本地显示链路中实时数据与历史地图之间缺少坐标变换的问题。
