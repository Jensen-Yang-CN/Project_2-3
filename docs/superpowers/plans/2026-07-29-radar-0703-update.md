# 0703 雷达与 SLAM 更新实现计划

> **面向 AI 代理的工作者：** 在当前会话内使用执行计划技能逐项实现。当前目录不是 Git 仓库，因此不执行提交步骤。

**目标：** 接入 0703 新版 GNSS/GICP 卡尔曼融合，更新 210→211 外参，并在保留后方三雷达接收的同时将它们排除出融合点云。

**架构：** `CalibrationConfig` 继续作为唯一外参来源；`RadarFusionPolicy` 独立声明融合雷达名单；`RadarFusionManager` 只消费策略名单；`LidarGnssSlam` 选择性迁移 0703 的预测、协方差估计、异常拒绝和卡尔曼更新，保留当前节点接口。

**技术栈：** C++17、Qt 5、Eigen、PCL、nano_gicp、CMake/CTest。
