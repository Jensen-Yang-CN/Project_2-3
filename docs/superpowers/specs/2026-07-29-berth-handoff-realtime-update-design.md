# 2026-07-29 泊位检测实时算法更新设计

## 目标

将 `berth_detection_handoff_realtime_20260729.zip` 中的最新版泊位算法规则按语义合并到现有 PointCloud 项目，同时保留项目已经完成的蓝色盲区回显、黄绿色实时框、U 型泊位开口不绘线、雷达融合、桥梁检测和 20/72 字节新版投递协议。

## 合并边界

- 不整包覆盖公共类型和 UDP 协议。
- 不引入压缩包中的旧版 `16 + 68` 字节协议。
- 不删除当前 GNSS/INS 有效性字段和 `CoordinateLibrary` 来源语义。
- U 型检测采用新版 20 m × 2 m、从边中点向外的 BEV 开口搜索区域，并取消开口搜索和边点统计的 Z 高度过滤。
- 普通检测优先选择射线未命中的方向；全部命中时按边点数回退。
- 锚点恢复结果只有在恰好一个方向未命中时改变开口，否则保留锚点连接边。
- 宽长轴交换时统一映射开口、边点数、高度和船距等所有边索引字段。
- 实时 U 型框相交时按非开口边点数与有效高度边数量仲裁。
- 实时框与坐标库回显框冲突时保留实时框，抑制蓝色回显框。
- 删除 U 型和一字泊位每帧图片/TXT 调试落盘，保留内存调试消息和界面显示数据。

## 验证

- 开口矩形搜索区域与锚点恢复规则回归测试。
- 角度跨 180° 的宽长轴交换和边字段映射测试。
- 实时框之间、实时框与坐标库框之间的冲突优先级测试。
- 泊位协议 V2 回归测试，确认未退回旧协议。
- 主程序 Release 构建。
