# SLAM 仅显示实时扫描层设计

## 目标

SLAM 视图只绘制随当前船体位姿更新的实时世界系扫描，不再绘制固定的累计关键帧地图层，消除两层在不同处理时刻暂未重合造成的视觉偏移。

## 数据边界

- `m_slamLiveScan`：继续显示，是当前帧经 SLAM 位姿变换后的世界系点云。
- `m_slamMapCloud`：停止绘制，但继续累计，用于保存地图、地图导出和其他后台功能。
- 船体图标与轨迹：保持显示。
- 清空、保存和加载地图接口：保持现有行为，不删除用户地图文件。

## 验证

新增无界面的显示策略测试，固定累计层默认不可见、实时扫描层默认可见；随后运行全部 CTest 并完整构建主程序。
