# 禁用启动时自动恢复 SLAM 地图：设计说明

## 目标

程序启动后，SLAM 地图区域保持空白，不再自动读取并显示上次加载或保存的离线地图，避免旧地图干扰当前 PCAP 解析和地图拼接效果判断。

## 方案

仅删除 `MainWindow` 构造阶段对 `restoreLastSlamMap()` 的零延时调度。

保留以下能力：

- 用户点击“加载地图”后手动加载一张或多张 `.slammap` 文件；
- 多地图 ENU 对齐与拼接；
- 地图保存；
- 最近地图路径的记录以及 `restoreLastSlamMap()` 辅助函数，便于以后重新启用。

## 行为边界

- 启动程序：不显示离线历史地图；
- 点击“加载地图”：清理并替换当前离线地图显示，按所选文件加载或拼接；
- 实时 PCAP/SLAM：保持现有处理逻辑不变；
- 不删除磁盘上的 `.slammap` 文件，也不清除最近地图配置。

## 验证

调整源码接线回归测试，明确断言启动构造流程中不存在 `restoreLastSlamMap()` 的自动调度，同时继续断言手动多选加载及后台拼接流程仍然存在。随后构建并运行 `slam_map_stitching_tests`，再构建主程序 `PointCloud`。
