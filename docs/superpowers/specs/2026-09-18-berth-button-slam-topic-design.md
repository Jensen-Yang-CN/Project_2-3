# 独立泊位按钮与 SLAM 地图总线修复设计

目标：恢复工具栏独立“泊位检测”按钮，并让 SLAM 生成的关键帧和实时扫描通过现有 `slam/keyframe`、`slam/scan_cloud` 总线到达界面、保存和其他订阅节点。

范围：只修改 `mainwindow.cpp/.h`、`DloSlamNode.cpp/.h` 和对应源代码回归测试；不改变 SLAM 算法、地图格式、泊位算法和投递协议。

设计：桥梁与泊位各自维护开关状态。融合点云始终送入 SLAM，仅在泊位开关开启时送入泊位节点。DLO 在保留兼容 Qt 信号的同时，将关键帧和世界系扫描发布到现有 Topic。

成功标准：工具栏出现“桥梁检测”和“泊位检测”；两者能独立开关；SLAM 关键帧进入界面地图；源代码回归测试和主程序编译通过。
