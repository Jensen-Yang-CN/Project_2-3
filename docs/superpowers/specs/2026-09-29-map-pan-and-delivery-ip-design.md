# 地图视角拖动与投递 IP 持久化设计

## 目标

在离线 PCAP 回放和已加载 `.slammap` 的地图视图中，用户可以将视野平移到关注区域；信息投递对话框中的对端 IP 可以保存并在下次打开时恢复。

## 交互

- 俯视地图使用左键拖动平移，滚轮缩放。
- 3D 地图保留左键旋转，增加右键拖动平移，滚轮缩放行为不变。
- 平移作用于当前整幅显示场景，使历史点云、实时点云、泊位框和船位保持相对位置不变。
- 不增加新的工具栏按钮或模式切换。

## 投递地址配置

- 对端 IPv4 地址默认值为 `101.1.101.105`。
- 对话框确认有效地址后，将其写入程序实际加载的 `config.json`，键名为 `network.delivery_remote_ip`；下次打开对话框时读回该值。
- 如果保存配置失败，记录清楚的错误信息；本次投递仍可使用对话框当前输入地址。
- 其他已有配置项及信息投递端口不变。

## 实现边界

- 地图视角只改变绘制矩阵中的相机平移量，不修改点云、SLAM 位姿、泊位坐标或地图文件内容。
- 3D 拖动用视野距离和窗口高度换算屏幕像素到平移量；俯视图沿用现有米/像素换算。
- IP 持久化复用 `AppConfig` 当前加载的配置路径，更新 JSON 中单个键并原子保存。

## 验证

- 单元测试覆盖俯视拖动方向、3D 平移方向与缩放比例，以及投递 IP 默认值、写入、重新加载和其他 JSON 配置保留。
- 手动检查 PCAP 累积 SLAM 地图、已加载 `.slammap` 的 俯视与 3D 拖动；确认左键旋转和滚轮缩放仍正常。
- 手动设置非默认对端 IP，关闭并重新打开投递配置对话框，确认显示保存值；默认配置缺少该键时显示 `101.1.101.105`。
