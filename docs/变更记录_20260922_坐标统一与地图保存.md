# 2026-09-22 坐标统一与地图保存修复

## 修改内容

### 1. 修复实时地图偏移

- 加载离线 `.slammap` 后，实时关键帧继续通过首个有效地理参考变换到离线地图的 ENU 坐标系。
- 修正关键帧变换逻辑：只变换关键帧 `pose`，不再直接变换关键帧 `cloud`。
- 地图合并流程只对点云应用一次位姿变换，避免实时地图被重复变换后产生偏移。
- 实时里程计、实时扫描点云和泊位同步结果仍使用同一显示坐标系。
- 历史地图保持黄色，实时地图保持绿色，两个图层继续叠加显示。

### 2. 保存地图只保存当前回放内容

- 新增当前回放会话的关键帧集合，不再直接把已加载的历史关键帧写入新地图。
- 新增当前回放会话的泊位集合，保存时不再混入历史泊位记录。
- 如果当前关键帧已经转换到显示/ENU 坐标系，保存时清除原始地理参考，避免重新加载时重复校正。
- 未加载历史地图时，原有 SLAM 保存流程保持不变。

## 使用效果

1. 先加载历史 `.slammap`。
2. 再加载 PCAP 回放并启动 SLAM/泊位检测。
3. 本地界面中实时绿色点云应与历史黄色点云处于同一位置。
4. 回放完成后点击“保存地图”，生成的新 `.slammap` 只包含本次 PCAP 回放数据及本次回放泊位。
